The candidate passed all four modules with readonly race tests and vet, the tagged example tests, compiled partner-guide snippets, and the real Nakama 3.41/Postgres two-client smoke on Linux ARM64. Cleanup is best effort: unknown allocation identities cannot be safely restarted, and dependencies ignoring cancellation can return after the terminal callback. A late known result is reclaimed while the process is alive. Restart failure preserves the original error and emits an operator log; reconciliation conditionally cleans storage rather than blindly deleting a replacement generation. Live fleet validation and human approval remain release gates.
